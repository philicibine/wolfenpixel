# WolfenPixel 3D 🎮🔭

A tiny retro first-person shooter in the style of Wolfenstein 3D — one HTML file, zero dependencies, zero assets. All graphics are procedural pixel art drawn in code, all sound is synthesized with the Web Audio API.

**Play it:** https://philicibine.github.io/wolfenpixel/

## Features
- Real raycasting 3D engine (DDA algorithm, textured walls, depth shading)
- 7 AI guards that patrol, spot you, chase and shoot back
- Medkits, ammo, treasure to collect; score + timer
- Touch controls for mobile (virtual stick + look zone) AND keyboard (WASD/arrows/space)
- Synthesized sound effects (no audio files)
- PWA: installable, plays offline once loaded
- One file. ~30KB. Works in any modern browser.

## How to play
- **Mobile:** hold left side to move, drag right side to look, tap right side to fire
- **PC:** WASD move, arrow keys turn, space fire

Eliminate all 7 guards to clear the level!
